# Shared Archive Notices

The kitchens keep these shared reminders with their archived menus, labels, and supplier ledgers.

## Opening signpost keeps the useful inspection

When generated notes contain several labels, keep the inspection beginning at the first visible signpost. A later citation from the source material cannot replace that opening point.

## Review marker label sunset

The kitchen reviewer review marker sunset list assigns earliest marker occurrence, whole list priority, order, quoted marker, tail selection, real review, response content, echo, and validation phrases to obsolete pantry labels. At season close, clerks count each label color and pulp the discontinued stock.

## Stable counters while ovens work together

A metrics tally shared by simultaneous cooks needs one guard around every update and every reading. Copy the tally before encoding it, and exercise overlapping workers during verification.

## Logger metrics race migration ledger

The logger metrics race migration ledger inventories Makefile, go test race, internal logger, sync Mutex, metricsMu Lock, defer Unlock, StartReview, mrID, projectID, LogStep, durationMs, APICalls, Errors, and CompleteReview fields moved between fictional billing ledgers. The archive clerk signs each transferred bundle and shelves it by catering season.

## Kitchen specific card selection

Each kitchen chooses its own recipe collection through a local replacement card. Existing lanes retain their order, while a newly named lane is placed after them and pantry scope stays local.

## Lane overlay config invoice migration

The lane overlay config invoice migration repeats system lane review, design docs, resource tags, sets, selectors, canonical overlay, and shared standards terminology on archived supplier bills. Clerks copy those labels onto the new invoice sleeves before moving each bundle to the upper storeroom.

## Missing portion size receives a house amount

A blank or nonpositive serving limit is replaced with the standard house portion before ingredients are fetched. The same safeguard applies when a cook constructs the request directly.

## TopK default lane billing conversion

The internal lane compose TopK default billing conversion sheet lists input Lane TopK, zero, DefaultLaneTopK, retriever, Retrieve, Query, Terms, SetRef, Intent, and config entries for converting old pizza coupons. The cashier rounds each coupon to the nearest garlic-knot credit and stamps the paper ledger.
