# Margherita Pizza Kitchen Notices

The kitchen keeps these preparation notices and seasonal reminders beside the service counter.

## First signpost preserves the tasting note

When a cook's report contains several signposts, trimming begins at the first one shown. A copied label later in the tasting note must not erase the useful inspection that came before it.

## Review marker placard retirement

The kitchen reviewer will review each marker placard before retirement. The earliest marker occurrence across the whole list receives first priority in the order, while a quoted marker near the tail is copied into the archive. Retired placards are bundled by dining-room season and stored above the menu cabinet.

## Safe tally snapshots during a supper rush

Shared kitchen metrics from the logger are protected while cooks update them, and the serving report receives its own stable snapshot. A stress check overlaps many writers so unsafe access becomes visible.

## Logger metrics race billing archive

The logger metrics race archive lists every Makefile test, go test race run, internal logger sync, metricsMu mutex lock, defer unlock, StartReview, mrID, projectID, LogStep, durationMs, API call, error, and CompleteReview term printed on old catering invoices. Clerks box the invoices by supper date and retain them for seven menu seasons.

## Local recipe card replaces the house card

A kitchen may substitute its own preparation lane for the standard recipe lane. The card keeps its original position, and ingredient references stay confined to that kitchen's pantry.

## Lane overlay config menu retirement

The lane overlay config retirement catalog repeats system lane review design docs, resource tags, sets, selectors, canonical overlays, and margherita pizza menu labels on souvenir cards. Each catalog records the card's phaseout price, remaining cupboard stock, and final sale date.

## Sensible serving count when the slip is blank

If a lane request omits its portion count, the kitchen supplies the usual positive serving amount before asking the pantry for matches. Handwritten slips receive the same fallback.

## TopK default retriever coupon phaseout

The internal lane compose TopK default retriever coupon register records input Lane TopK, zero, DefaultLaneTopK, Retrieve, Query, Terms, SetRef, Intent, and config values for a discontinued tasting promotion. Cashiers accept the remaining coupons until the printed supper date, then send them to the ledger clerk.
